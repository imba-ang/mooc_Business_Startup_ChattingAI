# 启思 · AI 创新陪练

一个面向高校创新创业课程的三阶创新思维陪练网页。产品将“破—扩—筛”教学方法实现为可持续推进的交互流程，强调学生先思考、系统再追问，最终自动整理为任务成果单。

## 功能

- “破”四问：事实、约束、假设、问题重构
- “扩”四维：对象、时间、空间、流程；每个维度可填写 0 个或多个方向
- “筛”四则：用户、痛点、资源、目标
- 从方案池中选择至少 2 个候选方向，通过四筛收敛表完成比较与自主决策
- 每道题支持回到上一题重新作答
- 思维反思与成果单导出
- 支持语音输入与实时文字识别，识别结果可在提交前修改
- 完成全部训练后播放彩色纸片和彩带喷射动画
- 进度自动保存、课堂展示模式、响应式布局
- 无第三方依赖，无需 API 密钥即可完整演示

## 网页启动

无需安装软件或配置运行环境，直接使用浏览器打开：

**[进入“启思 · AI 创新陪练”](https://imba-ang.github.io/mooc_Business_Startup_ChattingAI/)**

建议使用最新版 Chrome、Edge 或 Safari。学生的训练进度会自动保存在当前浏览器中；更换设备、浏览器或清除浏览器数据后，原有进度不会保留。

## 操作提示

- 输入框中按 `Ctrl/Cmd + Enter` 可提交当前回答。
- 点击“上一题”可撤回上一次提交，并重新填写上一题。
- “扩”阶段可用“新增方向”和“删除”调整输入框数量，也可保留 0 个方向直接跳过。
- 点击输入框旁的“语音输入”并允许麦克风访问，识别内容会写入输入框；请检查并修改后再提交。
- 语音识别建议使用最新版 Chrome、Edge 或 Safari，并通过 HTTPS 网页访问。
- “任务成果单”会随回答实时更新，可随时复制内容或导出为 Word 文档。
- “重新开始”会清除当前浏览器中的本次训练进度。
