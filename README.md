# 启思 · AI 创新陪练

一个面向高校创新创业课程的三阶创新思维陪练网页。产品将“破—扩—筛”教学方法实现为可持续推进的交互流程，强调学生先思考、系统再追问，最终自动整理为迁移任务成果单。

## 功能

- “破”四问：事实、约束、假设、问题重构
- “扩”四维：对象、时间、空间、流程
- “筛”四则：用户、痛点、资源、目标
- 3—5 个候选方案的逐项比较与学生自主决策
- 创新检查、思维反思与成果单导出
- 进度自动保存、课堂展示模式、响应式布局
- 无第三方依赖，无需 API 密钥即可完整演示

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm run dev
```

打开 <http://127.0.0.1:5173>。

也可以直接使用任意静态文件服务器打开本项目。所有陪练逻辑均在浏览器本地运行，学习数据只保存在当前浏览器的 `localStorage` 中。

## 操作提示

- 输入框中按 `Ctrl/Cmd + Enter` 可提交当前回答。
- “迁移任务成果单”会随回答实时更新，可随时复制或导出为 Markdown。
- “重新开始”会清除当前浏览器中的本次训练进度。
